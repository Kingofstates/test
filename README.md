# Amazon Clone E-Commerce Store

A fully responsive, feature-rich Amazon-like e-commerce web application built with HTML5, CSS3, and modern JavaScript.

## Features
- **Responsive Amazon Header & Navigation**: Authentic Amazon UI including search bar with category selector, deliver-to location, and cart counter.
- **Product Catalog & Filtering**: Browse curated products across Electronics, Fashion, Home & Kitchen, and Beauty with star ratings and Prime-style badges.
- **Interactive Shopping Cart Sidebar**: Add items, adjust quantities, calculate real-time subtotal, and remove products.
- **Search & Category Navigation**: Instant search filtering and category tabs.
- **Checkout Simulation**: Complete checkout workflow with success notifications.

## Tech Stack
- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript (ES6+)
- FontAwesome Icons
